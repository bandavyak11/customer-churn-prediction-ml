Customer Churn Prediction (Machine Learning Project)
📌 Project Overview
This project predicts customer churn using machine learning techniques. The goal is to identify high-risk customers and generate insights that help businesses improve retention.
The project includes data cleaning, EDA, feature engineering, model training, evaluation, and business interpretation.

Pandas, NumPy
Matplotlib, Seaborn
Scikit-learn
Jupyter Notebook

📈 Results & Insights
Achieved 80%+ accuracy using Random Forest
Payment method, contract type, and monthly charges strongly influence churn
Customers with "Month-to-Month" contracts show the highest risk
Insights can help retention teams target high-risk segments
🧩 Business Impact
Reduce churn by identifying at-risk customers
Improve customer lifetime value (CLV)
Support retention strategies and customer success teams
